# Elite party cues case study

This public case study shows how Peer2Paper separates source verification, numerical reproduction, and robustness findings. It is an independently authored aggregate summary, not a copy of the underlying research package or the complete internal audit.

## Research source

Pink, Sophia L.; Chu, James; Druckman, James N.; Rand, David G.; and Willer, Robb. “Elite party cues increase vaccination intentions among Republicans.” *Proceedings of the National Academy of Sciences* 118(32), 2021.

- [Article and licence statement (PMC)](https://pmc.ncbi.nlm.nih.gov/articles/PMC8364165/)
- [DOI record](https://doi.org/10.1073/pnas.2106559118)
- [Author-deposited materials (OSF)](https://osf.io/rb3cn/)

The article is marked [CC BY-NC-ND 4.0](https://creativecommons.org/licenses/by-nc-nd/4.0/). The audited OSF project did not record a project-level reuse licence, so this repository links to those materials rather than copying them.

## What the audit found

The primary-source report was verified for the displayed coefficient, interval, test statistic and p value. Within a frozen seven-candidate robustness registry, the adjusted HC2 path retained statistical support while the unadjusted HC2 path remained positive without statistical support. The comparison changes the adjustment bundle, covariate definition and listwise analytic sample together; it is not evidence that any one element alone caused the change.

The canonical audit did not execute its frozen author-directed reproduction targets, so it classified numerical reproduction as not assessable. It also preserved a conflict between the paper/code and supplementary wording about the analyzed vaccination-status population.

See [`result.json`](result.json) for the reviewed machine-readable public record.

## Publication boundary

Included here:

- Peer2Paper-authored narrative and aggregate statistics
- explicit scope and limitations
- attribution and authoritative source links

Excluded from public Git:

- participant-level data
- copied paper and supplementary PDFs
- third-party analysis code without a recorded reuse licence
- hidden benchmark answers
- complete run records, reviewer packets and internal evidence bundles

The repository MIT licence applies to the Peer2Paper-authored files only. It does not relicense the linked paper, data, code, or supplementary materials.
